# English Career Playbook

> Interactive playbook and practice web app to develop functional English for daily life, technical work, and global tech interviews. Deployed via GitHub Pages.

---

## 🎯 Purpose

This project is an interactive career companion designed to build fluency and confidence in English for software engineering careers, global technical interviews, and day-to-day international collaboration.

Based on the [English Career Playbook](english-career-playbook.md) by Yamid Cueto.

## 🚀 Key Pillars

1. **Sentence Builder Lab:** Active construction of professional sentences using real-world patterns (subject + verb + complement, past experience, intent, questions).
2. **Block Bank & Active Vocabulary:** Tech and survival phrases for meetings, standups, and daily engineering discussions.
3. **Interview Simulator:** Structured questions (STAR method, system design, background, motivation) with real-time feedback cues.
4. **Pedagogical Progress Tracking:** Session logs and self-evaluation metrics to track continuous improvement.

## 🌐 Deployment

This app will be hosted on **GitHub Pages**.
